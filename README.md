# Hotel Booking App

Aplikasi booking hotel dengan alur pencarian kamar, pemilihan tanggal, dan konfirmasi pemesanan.

## 🚀 Demo
https://booking-app-xi-kohl.vercel.app/

## 🛠️ Tech Stack
- Next.js
- Tailwind CSS
- Postgre SQL Neon

## ✨ Fitur
- Listing & pencarian kamar hotel
- Form booking dengan validasi tanggal
- Halaman konfirmasi pemesanan
- Terintegrasi payment gateway (Midtrans)
- Responsive (mobile-friendly)
